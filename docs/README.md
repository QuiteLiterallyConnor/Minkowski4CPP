# GitHub Pages documentation

The published documentation starts at [index.md](index.md).
Pages use Jekyll front matter, the shared `_layouts/default.html`, and
`_data/navigation.yml`. No remote theme is required.

Enable **GitHub Actions** as the source in repository **Settings > Pages**.
The [Pages workflow](../.github/workflows/pages.yml) builds this directory
and deploys it on changes to `main` or a manual run.

See [contributing.md](contributing.md) for maintenance and preview instructions.
